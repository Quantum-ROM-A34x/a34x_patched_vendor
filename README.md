# Samsung Galaxy A34 5G — Patched Vendor

A patched **Vendor for the Samsung Galaxy A34 5G (`a34x`)** designed to work across supported A34 variants running the bootloaders listed in [`supported_bootloaders`](./supported_bootloaders).

The vendor includes patches to improve cross-variant and cross-bootloader compatibility, with the main work inspired by the A34x Multi-TEE implementation from UN1CA.

> ⚠️ **Check `supported_bootloaders` before flashing.**
>
> Do not flash this vendor on an unsupported bootloader.
